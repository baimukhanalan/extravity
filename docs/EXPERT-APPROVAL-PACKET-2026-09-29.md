# Extravity — пакет решений для экспертной проверки

**Дата среза:** 29 сентября 2026 года. **Назначение:** вернуть владельцу проекта однозначные решения до массовой публикации карточек. Это перечень вопросов и фактов о продукте, а не юридическое заключение.

## 1. Что уже работает и что пока закрыто

| Поток | Фактическое состояние | Почему не опубликовано автоматически |
| --- | --- | --- |
| Telegram | 66 подключённых публичных каналов; после обновления сервиса Railway состояние вновь `connected`, последней ошибки нет. В базе 227 карточек `PENDING_REVIEW` и 234 `SUSPICIOUS`. | Канал часто репостит чужого организатора; возраст, дедлайн и право на медиа не гарантированы. |
| Сайты | 38 текущих/будущих карточек из официального индекса [Astana Hub Events](https://astanahub.com/en/event/) после расширенного прогона; все в очереди. | На сайте есть изображения, но права на их повторное хранение/показ у Extravity не установлены; некоторые события уже начались или не предназначены школьникам. |
| Новости | Автоматический сбор из официальных лент MIT, NASA и Google. 3 пересказа проверены вручную и опубликованы; 18 материалов в очереди. | Необходима редакционная проверка релевантности и фактов. Полные статьи и чужие изображения не копируются. |
| Instagram / WhatsApp | Плановые задания выключены. | Нет подтверждённого набора доступных, разрешённых и пригодных источников для регулярного сбора. |
| Публичный каталог | Пока нет опубликованных возможностей. | Правило продукта требует готового фото/видео с подтверждёнными правами. В базе 478 медиафайлов имеют состояние прав `PENDING`; один `REJECTED`. |

Сбор и хранение кандидата **не означает** разрешение его публиковать. Важное уточнение: 69 Telegram-карточек имеют будущий дедлайн и готовый файл с неподтверждёнными правами; явный минимальный возраст не старше 18 указан лишь у пяти, и даже это не доказывает пригодность школьникам Казахстана.

## 2. Решения, которые просим вернуть

Отметьте для каждого пункта `ДА`, `НЕТ` или `УСЛОВНО`, а при условии укажите точное основание/документ, объём разрешения, срок, обязательную атрибуцию и ответственного.

| ID | Вопрос для эксперта | Решение / основание / условия |
| --- | --- | --- |
| M1 | Может ли Extravity скачивать, хранить, обрезать, конвертировать и публично показывать фото/видео из постов **каждого конкретного организатора** в Telegram? Достаточно ли публичности поста или требуется лицензия/согласие правообладателя? |  |
| M2 | То же для изображений с `cdn.astanahub.com`: вправе ли мы переиспользовать их вне Astana Hub, в карточках своего сайта и в рекламе? Если только по разрешению, кто может его дать — платформа или автор отдельного события? |  |
| M3 | Можно ли использовать кадр, обложку и фрагмент Reels/Instagram-публикации, либо только ссылку/официальное встраивание? Кто подтверждает права на музыку, лица несовершеннолетних и сторонние логотипы? |  |
| M4 | Допустим ли запасной лицензированный визуал, явно помеченный как иллюстрация, если оригинальное медиа нельзя использовать? Пользовательская спецификация сейчас требует фото/видео у каждой карточки. |  |
| P1 | Должна ли карточка для школьника публично указывать источник/ссылку/автора фото и текста? Текущее пожелание владельца — показывать организатора, но не ссылку на канал. Можно ли хранить источник только во внутреннем журнале? |  |
| P2 | Какие условия необходимы для автоматического чтения публичных страниц, RSS и каналов: разрешение организатора, ограничения использования, частота запросов, хранение полных текстов и срок удаления? |  |
| P3 | Разрешено ли собирать сообщения из закрытых Telegram/WhatsApp-групп? Нужны ли согласия администратора и участников, и можно ли вообще публиковать оттуда материал без отдельного подтверждения? |  |
| C1 | Как подтверждать истинного организатора, когда публикация — репост агрегатора? Достаточно ли первичного объявления/регистрационной страницы для имени организатора и возможности «подать заявку»? |  |
| C2 | Как действовать при противоречащих дедлайнах на странице организатора, при отсутствии возраста, гражданства, стоимости или даты закрытия? Предложение: не публиковать до проверки. |  |
| D1 | Какие документы, согласия ученика и родителя/опекуна, сроки хранения и ограничения передачи данных нужны для заявок от имени несовершеннолетних на внешние сайты и за рубеж? |  |

**Нужный формат ответа:** `ID → ДА/НЕТ/УСЛОВНО → ссылка/файл основания → условия (атрибуция, срок, территория, виды медиа) → кто подтверждает → дата решения`. При `УСЛОВНО` разрешение не применяется автоматически до выполнения условия.

## 4. Гейт перед публикацией каждой карточки

Карточка может стать публичной, только если проверены: первичный организатор и его контакт/сайт; соответствие школьникам из Казахстана (возраст, гражданство, язык, цена); реальная открытая регистрация и актуальный дедлайн; рабочий маршрут подачи; точное название; хотя бы одно фото/видео со статусом `READY` и документированным правом использования; отсутствие лишних персональных данных.

Без всех этих условий кандидат остаётся во внутренней очереди. Пожалуйста, не присылайте логины, коды подтверждения, секретные ключи или документы детей в ответ на этот пакет.
