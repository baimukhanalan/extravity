# Безопасность и персональные данные

Платформа работает с данными несовершеннолетних, поэтому безопасность — приоритет.

## Реализовано

- **Пароли** — bcrypt (cost 10), в открытом виде не хранятся и не логируются.
- **Сессии** — JWT (HS256, `jose`) в **httpOnly** cookie; `secure` в проде, `sameSite=lax`, срок 30 дней.
- **Авторизация на сервере** — `requireUser/requireRole`; проверка владения объектом (защита от IDOR).
- **Валидация входных данных** — Zod во всех Server Actions.
- **Аудит** — `audit_logs`: входы, регистрация, старт/смена статуса заявки, модерация, согласия и др.
- **Приватность документов** — не публичны; в демо загрузка эмулируется (`isMock`).
- **Транспорт** — HTTPS (Vercel), TLS до БД (`sslmode=require`).
- **Секреты** — только через environment variables; в репозитории нет секретов (`.env*` в `.gitignore`, есть `.env.example`).
- **SEO-изоляция** — `/app`, `/admin`, `/api` закрыты в `robots.txt`; приватные страницы не индексируются.
- **Внешние ссылки** — `rel="noopener noreferrer nofollow"`, открываются в новой вкладке.

## Осознанные ограничения демо / план на production

- **RLS (Row Level Security)** — сейчас изоляция данных обеспечена серверными проверками владения;
  при переходе на Supabase/пул с ролями добавляются политики RLS на уровне БД.
- **Хранилище документов** — Supabase Storage / S3 с **signed URL** и ограниченным TTL, MIME-валидация,
  лимит размера, запрет опасных расширений, антивирус-скан (архитектурно предусмотрено).
- **MFA для администраторов**, session revocation, экспорт/удаление данных пользователя.
- **Родительское согласие** для несовершеннолетних (модели `parent_*`, `consents` заложены).
- **Rate limiting, secure headers, CSRF** — на уровне Cloudflare/edge и middleware при выводе в прод.
- **Защита от SSRF** при обработке пользовательских ссылок в парсере (валидация URL, запрет внутренних адресов).

## Данные несовершеннолетних

- Минимизация: собираем только необходимое для подбора.
- Передача данных организатору — только после отдельного явного подтверждения пользователя.
- Никаких обещаний гарантированного поступления; trust score помечает подозрительные предложения.
